# Personal Portfolio - React + Vite

This is a modern, fully responsive personal portfolio built with React and Vite. It showcases skills, certifications, projects, and achievements using smooth on-scroll animations and parallax effects.

## Tech Stack
- **Framework:** React + Vite
- **Styling:** Vanilla CSS (Glassmorphism & Custom Themes)
- **Animations:** Framer Motion & CSS Transforms
- **Parallax:** React Scroll Parallax

## Live URL
[https://protofolio-mu-olive.vercel.app/](https://protofolio-mu-olive.vercel.app/)

## Features
- Fully responsive layout (Mobile, Tablet, Desktop)
- Parallax scrolling effects on background shapes
- On-scroll reveal animations (respects user's `prefers-reduced-motion` settings)
- Dark/Light Theme toggle

## Local Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/GVK-Sindhu/your-repo-name.git
   cd your-repo-name
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
